# Application Process in Sherpa Platform

## Main Dashboard Navigation
1. Click "Quote on Exchange"
2. Enter customer information:
   - Zip code
   - Household size
   - Income
   - Age

## Building Quote
### Example:
- Single household
- Income: $20,000
- Age: 47

## Starting Application
1. Quote customer → Hit "Start Application"
2. System automatically searches marketplace for existing applications
3. If found: Use existing (pre-filled information)
4. If not found: Start new application

## Using Existing Applications
### Benefits of using existing app:
- All information carries over
- Eliminates duplicate work
- Faster enrollment process
- Less chance for errors

**Always check for prior year applications first**

## Important Household Rules
⚠️ **Critical:** Include ALL household members on taxes, even if not getting coverage

**Customer:** "I just need coverage for myself"
**Agent:** "Are you married? Do you claim any dependents?"
**Customer:** "Yes"
**Agent:** "We need to put everybody on the application"

**Rule:** Everyone on taxes = Everyone in household
(Even if not all getting coverage)

## Application Settings

### Communication Preferences
**Paper notices:** ALWAYS select "Send by mail"
**Reason:** "Many people don't check email/texts, think it's spam, might miss critical coverage letters"
**Hard copy** = "They can't say 'I never got it'"

### Tobacco Use
**ALWAYS SELECT: NO**

**Reasons:**
- Healthcare.gov has no restrictions
- Can enroll with ANY condition (HIV, cancer, etc.)
- Selecting YES increases premium
- Could eliminate subsidy qualification
- Creates payment collection requirement

## Special Populations

### High-Income Scenarios
If income > $100,000 and kids on Medicaid/CHIP:
"When we enter $100,000/year, your kids will no longer qualify for Kid Care. We need to find a plan for everyone."

**Opportunity:** More enrollments, better coverage
"Kids on Medicaid are limited to certain doctors. Blue Cross Blue Shield network offers more options."

### Documentation Requirements by Population
- **American Indian/Alaska Native:** Select NO (don't qualify for healthcare.gov)
- **Incarcerated individuals:** Don't qualify for healthcare.gov
- **Hispanic/Latino question:** Optional - can skip (select decline)
