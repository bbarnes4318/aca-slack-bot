- Must have LIVE access (not PDF)

### Document Timeline Changes
- **OLD:** 90 days to collect documents
- **NEW:** 30 days only
- Critical for January 1st effective dates

### Key Compliance Reminders

#### ✅ ALWAYS:
- State "recorded line" at beginning
- Get clear "YES" for consent
- Mention coinsurance, deductible, max out-of-pocket
- Complete verification on EVERY call
- Collect documents same day
- Build confidence before asking for SSN

#### ❌ NEVER:
- Skip compliance steps
- Tell customer to call back with documents
- Write Golden Rule policies
- Mislead or steer for financial benefit
- Rush through verification

### Open Enrollment Preparation:
- All agents in same boat
- Appointments still being processed
- State routing being finalized
- NPN overrides being set up
- Be ready for Saturday start

### Success Formula:
- Follow the script
- Build rapport
- Be confident
- Educate, don't sell
- Get documents immediately
- Ask for referrals
- Protect your license

### Remember
"This is a traditional sale. If you come from Medicare, remove all fear. This is not that type of industry. It's much more relaxed, much less compliance-heavy. Everything else is free game."
